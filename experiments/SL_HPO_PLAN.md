# VL-DistMult + SL(8)：接入与调参计划

2026-09-06；状态：本地实现与校验，**未启动新增 GPU 搜索**。
现有 geometry v1 队列、6 小时上限和已完成原作者复现均保持独立。

## 这次调的是哪个模型

VL-KGE 是论文框架，DistMult 是已有知识图谱打分模型。论文中的
VL-DistMult 是将二者结合的多模态模型，不是论文从零提出 DistMult。
我们已复现其 WN9-IMG test MRR=0.9350893979，与论文 0.935 三位小数一致。

这次新增的是 **VL-DistMult + SL(8) 关系残差（混合模型）**：

1. 作者的实体 ID、冻结图像/文本特征、768 维平均融合、768 维关系表不改。
2. 作者原始 DistMult 分数完整保留。
3. 额外将融合实体/关系分别投影到 63 个无迹矩阵坐标，映射到 SL(8)。
   头尾实体共享投影；关系矩阵左乘头实体矩阵，与尾实体比较。
4. 有界 SL 分数通过零初始化门控加到原分数上。

它与旧的「768→63 后完全使用几何打分」不是同一个模型，结果不能混记。
本次不声称全部计算发生在 SL 空间，也不保证新增分支必然改善效果。
精确关闭分支时，原模型初始化、分数、loss、梯度和一次 Adagrad 更新
必须与原作者模型逐位一致。零初始化但可学习的 gate 不等于一直关闭。

新启动器调用原作者训练函数、loss、负采样、完整验证、early stopping
和最佳 checkpoint 选择；不把旧 geometry trainer 的梯度裁剪等带入。
改动参数另存记录，原 YAML 和作者模型文件不覆盖。门控允许负值，若最终
gate<0，须报告为反向残差修正，不能解释为“SL 距离越近越好”的正权贡献。
SL 核心是 Gregory-12 局部矩阵对数近似，不是全局精确测地距离。

## 搜索范围

| 参数 | 扩展候选范围 | 第一批固定/锚点 |
| --- | --- | --- |
| batch size | 128、256、512、1024、2048 | 256、512、1024 |
| learning rate | 0.003、0.01、0.03、0.05、0.1、0.2、0.3 | 0.01、0.03、0.1 |
| 每条正例的负样本数 | 25、50、100、200 | 100 |
| SL 坐标映射尺度 | 0.03、0.1、0.3、1.0 | 0.1 |
| 坐标约束半径 | 0.25、0.5、0.75 | 0.5 |
| 残差最大权重 | 0.1、0.3、1、3 | 1 |

这些是**待搜索范围，不是已经跑过的组合**。上限 batch、负样本数及半径
必须先通过显存/数值检查；不凭旧的小配置显存推断大配置一定能跑。

所有因素直接相乘有 6,720 组/残差方法，当前不作全排列。
先比较训练参数，再有限扩展残差参数。映射尺度和可学习投影、残差权重
和归一化尺度之间可能存在冗余，因此首轮扩展每个配置至多改变一个几何因素。
这不是交互效应的完整实验，也不是严格的单因素消融（各行训练参数同时
变化）；不能据此归因单个结构参数的收益。后续若有效，再围绕验证集优胜
区域联合搜索，并补相同训练配置下的结构消融。

固定：Adagrad、作者 loss、768 维原表示、SL(8)、冻结 CLIP、平均融合、
patience=50、每轮完整验证、gate 初值=0、训练集一次性校准。
归一化尺度固定为 `max(训练校准 std, 4×radius², 1e-6)`，中心为训练校准均值。
该下限是双方相同的稳定性约束，当前不作为 HPO 因素。
真实 WN9 训练数据的短 CPU 检查发现：只用初始 std，在 lr=0.1 下两步后
约 98.6% 的 SL 分支输出已饱和；加入该下限的 12 步检查中饱和比例为 0。
这不是正式训练、验证 MRR 或长期稳定性证明。检查记录在
`artifacts/distmult-sl-calibration-diagnostic-v1.json`，后续逐轮记录固定
训练探针的分数差异与饱和比例，不能仅看 loss 下降。
不在这一轮混入 Adam、weight decay、dropout、特征解冻、融合方式或维度
调整。这些需要单列架构/优化器消融，不能声称“完全相同原框架仅换 SL”。
`score_chunk` 是显存执行参数，不按准确率挑选；变更须先做数值等价检查。

## 分批执行

### 0. 正确性与测速

- 原 VL-DistMult、DistMult+欧氏残差、DistMult+SL 残差各 2 轮，完整验证。
- 不计算 test。记录训练/评估耗时、GPU 峰值、校准分布、gate 和 SL 数值诊断。
- 原框架的 query-by-query 评估与旧 geometry 批量评估速度不同，必须重测。
- 确认首步和后续 SL 投影有有效梯度，检查残差是否饱和成常数。

### 1. 六个训练参数锚点

`(lr,batch)`：`(.1,512)`、`(.03,512)`、`(.01,512)`、
`(.03,256)`、`(.1,256)`、`(.1,1024)`；均 100 负例。

每组同时安排三种方法，共 **18 次 × 最多 30 轮**。建议先授权新增
8 小时的有限批次；这是建议，不是已经获得预算或已经启动。
预算内可对每方法的作者参数点及另一有希望的点再从头训练到 100 轮。
若测速显示不足，按完整的三模型配置组缩减，不单独减少较慢方法的机会。

### 2. 扩展搜索与逐级确认

预先生成确定性的 48 个不重复训练配置，覆盖表中所有训练参数取值。
三种方法共享这些训练配置，欧氏/SL 残差使用逐项匹配的额外参数。

| 阶段 | 每方法配置数 | 每次最多轮数 | 是否允许 test |
| --- | ---: | ---: | --- |
| 扩展初筛 | 48 | 50 | 否 |
| 复筛 | 16 | 100 | 否 |
| 完整验证确认 | 6 | 200 | 否 |
| 锁定配方、多 seed | 1 × 3 seeds | 200 | 各运行结束后一次 |

每次重新初始化，不使用原 best-only checkpoint 假装连续训练：作者未保存
完整采样器/RNG 状态，阶段续跑不能保证等价。每一阶段用 seed42；锁定后
共同使用 seed42、2026、2027，不挑最好的 seed。最终报告 mean±std。

晋级按验证 MRR，但保护作者配置和一项后段仍有明显提升的慢启动配置。
如果作者配置也很差，先检查实现/数值，不以“前 10 轮落后”直接淘汰。
作者原 DistMult 最佳验证在第 192 轮，已有事实不支持用 10 轮排名代替收敛排名。

上述扩展阶段在不早停时为 **17,400 个模型轮次**；另有测速/锚点预算。
仅以旧原 DistMult 38.24 分钟/200 轮作粗略“基线等价工作量”，约 55.4
GPU 小时；**这不是新版 SL 的实际耗时估计**，实际可能更长。
完整搜索属于数天量级的工作提案，须在测速和预算确认后分批推进。

## 公平性、测试集与停止条件

- 保留论文原参数成绩，同时报告各方法相同搜索次数/轮数预算下的调优成绩。
  额外记录 GPU 小时与更新步数；不同 batch 的相同 epoch 不代表相同更新数。
- 原 DistMult 与匹配容量欧氏残差都不能省略：否则无法区分调参/额外参数
  和 SL 几何自身的收益。相同 trial 数也不等于相同 GPU 时间，两者均披露。
- 调参不读取 test 指标。新启动器会在原训练器最终 test 评分前拦截，
  保存 `completed_validation_only`，不写虚构 test 分数。
- “不计算 test”不意味着原发布协议从未用过 test 正例：为对齐作者结果，
  其 all-split 混合方向 filter 仍保留用于负例过滤。以后若改为严格 train-only
  协议，必须统一重跑全部对照，不能仅更改 SL。
- NaN/Inf、SL 局部对数风险、退化校准或 OOM 需要单独记录为无效/待诊断；
  不静默改 batch、换 loss、丢坏 batch 或把无效试验算作正常低分。
- 每个完成项备份配置、源代码 hash、训练日志、完整验证成绩及最佳权重。
- 新队列必须有明确墙钟上限、GPU 独占锁和停止/备份机制。尚未设置新增
  授权小时数，不自动延长现有 6 小时队列，也不替用户关闭服务器或计费。
